幻想时刻

版本 —

对话式 AI 视频生成桌面软件。云端接口（百炼通义万相 / SiliconFlow）+ 本地免密钥（LTX-Video 2B）双轨生成，智能模型路由，多通道并行自动更新。

能力边界（如实说明）

  • 真实生成需自备 API Key；无 Key 且未装本地模型时仅能走「自检模式」，产出带水印的样例视频，非真实 AI 结果。
  • 海外模型通道本机网络实测不可达，仅保留接口位，探测到可达才启用。
  • 本地轨受显存限制：8GB 显存出片约 480p / 5 秒，单条数分钟。
  • 安装包未做代码签名，首次运行 Windows 可能提示风险，需手动放行。
